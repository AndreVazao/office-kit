## Regra de autoridade

- O contrato define **o que** estamos a construir.
- A arquitetura define **como as responsabilidades são separadas**.
- O roteiro define **em que ordem** avançar.
- O plano Diorama define **como usar a referência visual** sem tornar o Office Kit dependente dela.

Quando uma implementação ou uma conversa futura divergir destes documentos, voltar a estes ficheiros e propor uma alteração explícita antes de mudar o rumo.
